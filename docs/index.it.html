Non scrivi più solo codice — dirigi agenti. fluxtty è uno spazio di lavoro guidato da tastiera per supervisionare molte sessioni IA contemporaneamente, con l'efficienza modale che ha reso vim indispensabile.

L'idea

Prima scrivevi codice.
Ora supervisioni agenti.

Quando l'IA scrive il codice, il tuo lavoro passa dal digitare al dirigere. Ti serve uno spazio di lavoro pensato per questo — non un editor con un terminale aggiunto in un secondo momento.

Prima

  • Scrivere codice manualmente in un editor.
  • Un terminale per i comandi occasionali.
  • Eseguire i test da soli, leggere l'output, correggere manualmente.
  • Passare continuamente tra editor, browser e terminale.
→

Ora

  • Gli agenti scrivono; tu rivedi, guidi e sblocchi.
  • 8–12 sessioni aperte in parallelo: agenti, server, shell.
  • Monitora gli output, reindirizza gli agenti, correggi la rotta velocemente.
  • Il terminale è l'intero spazio di lavoro.
Funzionalità

Ogni elemento costruito per supervisionare agenti su larga scala.

Non è una skin per terminale. Il nucleo è un layout basato su righe, identità di sessione, modalità esplicite e instradamento dell'input sicuro per PTY — costruito per gestire 10 agenti aperti senza perderne traccia.

ROW

Righe a cascata

Le righe si impilano verticalmente. Le divisioni orizzontali vivono dentro una riga. Quando ci sono molte righe, lo scroll dello spazio di lavoro diventa il layout.

MODE

Barra di input modale

Le modalità Normale, Inserimento, IA, Terminale, Trova e Vista sono stati espliciti. La barra di input cambia etichetta, prompt e instradamento dei tasti in base alla modalità corrente.

FIND

Selettore di pannelli

/ apre la ricerca fuzzy su nome, gruppo, cwd e stato del pannello. Le frecce o j/k spostano; Invio mette a fuoco il pannello.

PTY

Pannelli xterm.js

I pannelli sono veri terminali xterm.js sostenuti da Tauri e portable-pty, con modalità terminale raw per TUI e app a schermo intero.

TAB

Completamento shell e slash

Tab completa comandi e percorsi tramite il backend Rust. I pannelli con agenti passano al completamento slash della lista comandi dell'agente rilevato.

AI

Rilevamento agenti

Gli agenti rilevati includono claude, codex, aider, gemini, opencode, goose, cursor, qwen, amp, crush e openhands.

ID

Identità di sessione

I pannelli tracciano nome, gruppo, cwd, stato, ultimo comando, ultimo codice di uscita, sessione tmux, stato dello schermo alternativo e tipo di agente.

CMD

Comandi dello spazio di lavoro

Il livello di azione supporta run, read, pipeline, broadcast, groups, new, rename, close, split, focus, note, clear, kill, paste e agent-send.

NOTE

Note di riga e ripristino

m apre il pannello note della riga. Le note di riga e il layout sono incluse nell'istantanea dello spazio di lavoro quando il ripristino è abilitato.

YML

Configurazione con ricarica a caldo

Finestra, font, colori, cursore, shell, tmux, input, IA dello spazio di lavoro, cascata, persistenza e valori predefiniti di sessione vivono in YAML.

Modalità

Una modalità. Uno scopo. Nessuna ambiguità.

Ogni modalità ha un colore, un'etichetta e una regola di instradamento distinta. La barra di input mostra esattamente dove vanno i tuoi tasti — allo spazio di lavoro, a una shell, a un agente, o a xterm raw.

NORMAL

Controllo predefinito dello spazio di lavoro. Muoviti con h j k l, crea con n, dividi con s, chiudi con q, rinomina con r, annota con m, cerca con /.

INSERT

Editor di riga verso il PTY. Premi i per digitare nel pannello attivo. Tab completa i percorsi shell o i comandi slash dell'agente rilevato. Esc torna a Normale.

AI

Input dei comandi dello spazio di lavoro. Premi a per il prompt dell'IA dello spazio di lavoro. Con model: none, vengono analizzati i comandi integrati esatti; con un modello configurato, le risposte possono emettere blocchi di azione strutturati.

TERMINAL

Controllo raw di xterm. Premi Ctrl+\ quando vim, htop, una TUI o un prompt di agente devono possedere direttamente la tastiera.

VIEW

Osservazione concentrata della riga. Premi v per isolare la riga attiva mantenendo lo stesso modello di pannelli e modalità.

IA dello spazio di lavoro

Dirigi il tuo spazio di lavoro in linguaggio naturale.

Premi a e descrivi cosa vuoi fare. L'analizzatore integrato gestisce le azioni comuni senza un modello. Imposta workspace_ai.model per instradare il linguaggio naturale verso qualsiasi LLM — Anthropic, OpenAI, Gemini o Ollama locale.

Esempi dell'analizzatore integrato
a run npm test in frontend
a run cargo test in group backend
a npm test in all sessions
a run cargo test then run npm test in api-agent
a new api in backend
a rename api to api-agent
a close idle
a close group scratch
a focus frontend
a group api-agent as backend
a note api-agent check migration output
a read tests
a clear db
a kill api-agent
a list
a !agent claude
Azioni immediate dell'analizzatorelist, status, help, read, focus e !agent vengono eseguite immediatamente.
Azioni di modifica dell'analizzatoreRun, new, rename, close, close-group, split, group, note, clear e kill vengono messe in coda tramite il flusso di conferma condiviso.
Blocchi di azione LLMI modelli configurati possono emettere azioni strutturate tra cui agent-send, run-await e pipeline.
Conferma

L'IA propone. Tu esegui.

Le azioni che modificano lo spazio di lavoro vengono messe in coda in un piano che rivedi prima che qualcosa venga eseguito. Una singola y esegue; qualsiasi altra cosa annulla. Il controllo resta a te.

Anteprima del piano
AI plan (3 actions):
  create new session "api" in group "backend"
  run "cargo test" in group "backend"
  rename "api" -> "api-agent"

execute? y/N
Installazione

Pronto in due comandi.

Prendi l'ultima versione per macOS, Linux o Windows — oppure compila dal codice sorgente con Tauri. La configurazione vive in un unico file YAML.

Homebrew
brew tap amoswzw/tap
brew install --cask fluxtty
Link
Ultima versione macOS / Linux / Windows Tutte le versioni build precedenti Codice sorgente Rust + TypeScript
Compilazione
git clone https://github.com/amoswzw/fluxtty
cd fluxtty
npm install
npm run tauri build
Configurazione
~/.config/fluxtty/config.yaml

input:
  live_typing: true
workspace_ai:
  model: none
